# Security

Learnarr stores media server tokens, AI keys and OpenSubtitles.com passwords (encrypted), so security reports
matter to us.

Please report a vulnerability privately through GitHub's
[security advisories](https://github.com/smoothless-io/learnarr/security/advisories/new), not in a public issue.
Include what's affected, how to reproduce it, and the version (System → Status). We'll answer within a week.

Only the latest release gets security fixes.
