# Learnarr and Sub-Optimal, side by side

Learnarr grew out of Sub-Optimal (kept as `jakubsz123/learnarr-legacy`, with a later `feature/books` branch).
This is what Sub-Optimal could do, whether Learnarr does it, and why. "Dropped" means left out on purpose;
"later" means worth doing, not done yet.

| Area                                                     | Sub-Optimal                                    | Learnarr        | Notes                                                                                                              |
| -------------------------------------------------------- | ---------------------------------------------- | --------------- | ------------------------------------------------------------------------------------------------------------------ |
| **Library**                                              |                                                |                 |                                                                                                                    |
| Browse Plex / Jellyfin                                   | Each user connected their own server           | Yes             | One server for the household, set by the admin. Simpler, and how the \*arr apps work.                              |
| Plex sign-in                                             | Token, server discovery through plex.tv        | Yes             | "Sign in with Plex" (PIN), or a token.                                                                             |
| Shows not on your server                                 | TVmaze search, episodes fetched on demand      | Dropped         | Learnarr works from the library you have. Searching a catalogue of everything is a different product.              |
| Continue watching                                        | Plex On Deck                                   | Partly          | Today shows what you studied last and the next episode of each show; not Plex's own On Deck.                       |
| Up next / adjacent episodes                              | Yes                                            | Yes             |                                                                                                                    |
| Sort the library by "% you know"                         | Half-built, unused                             | Later           | Shows each started episode's score; a library-wide "what can I watch" view is a good next step.                    |
| Posters from TMDB                                        | Yes                                            | Dropped         | Posters come from the media server, so no API key is needed.                                                       |
| **Subtitles**                                            |                                                |                 |                                                                                                                    |
| Media server track, then OpenSubtitles with your account | Yes                                            | Yes             |                                                                                                                    |
| Sound descriptions removed                               | Yes                                            | Yes             |                                                                                                                    |
| Embedded tracks via ffmpeg                               | Yes                                            | Later           | Plex and Jellyfin already serve most embedded text tracks; ffmpeg would add about 80 MB to the image for the rest. |
| Upload a subtitle file                                   | Yes                                            | Yes             | .srt, .vtt, .ass; replaces the episode's subtitle and keeps its cards.                                             |
| YouTube (yt-dlp + Whisper), channel polling              | Yes                                            | Dropped         | Out of scope for a media-server companion, and heavy to run.                                                       |
| **Words**                                                |                                                |                 |                                                                                                                    |
| AI word list per episode                                 | Yes, straight to a list                        | Yes             | Suggestions you learn, mark known or skip; nothing goes into study without your say.                               |
| AI providers                                             | OpenAI, Anthropic                              | Yes             | Plus anything OpenAI-compatible: Ollama, LM Studio, OpenRouter, Groq, Mistral, Gemini.                             |
| Lemmatisation (UDPipe)                                   | Czech and Spanish, 9 more pinned               | Yes             | 52 languages, every model pinned by checksum, downloaded on demand.                                                |
| Known words, seeded by level                             | Yes                                            | Yes             | Mature cards also count as known.                                                                                  |
| "% you know" per episode                                 | Yes, with tiers                                | Yes             | Coverage with four tiers based on the reading research.                                                            |
| Frequency colouring                                      | Zipf tiers                                     | Yes             | Rank and band from FrequencyWords, for 50 languages.                                                               |
| Interactive transcript                                   | Yes                                            | Yes             | Tap any word.                                                                                                      |
| Dictionary popup                                         | Wiktionary, DeepL fallback                     | Yes             | Wiktionary, cached, following plurals and conjugations to the base word. No DeepL: it would need a key.            |
| Translate a whole line                                   | AI                                             | Later           | Easy to add on the same AI connection.                                                                             |
| **Cards and study**                                      |                                                |                 |                                                                                                                    |
| Mine a sentence / make a card from a word                | Yes                                            | Yes             | The AI translates the word as used in that line.                                                                   |
| Decks per show                                           | Yes                                            | Later           | Cards are one list per language, searchable and filterable.                                                        |
| Review                                                   | Two buttons, doubling interval                 | Yes, better     | SM-2 with four buttons, learning steps, 20 new cards a day, undo.                                                  |
| Pre-watch drill                                          | Yes                                            | Partly          | Suggestions and the Words tab do the same job; a timed drill could come later.                                     |
| Anki                                                     | AnkiConnect through a server proxy; TSV export | Yes             | AnkiConnect from the browser, plus a file export Anki imports with no setup.                                       |
| **Progress**                                             |                                                |                 |                                                                                                                    |
| Streaks                                                  | Current and longest                            | Yes             | Current, longest, and twelve weeks of activity.                                                                    |
| Minutes watched, per-show stats                          | Yes                                            | Later           | Needs watch tracking, which comes with the live features below.                                                    |
| **Notifications**                                        |                                                |                 |                                                                                                                    |
| Web push                                                 | Yes                                            | Yes             | Works from a home-screen app on Android and iOS 16.4+.                                                             |
| ntfy                                                     | Yes                                            | Yes             | Per-person topic; self-hosted ntfy servers too.                                                                    |
| Practice reminders                                       | Yes                                            | Yes             | Once a day, only when cards are waiting and you haven't studied.                                                   |
| "Before you watch" on play                               | Yes                                            | Yes             | Plex and Jellyfin webhooks; plays matched to people by their media server user name.                               |
| **Watching**                                             |                                                |                 |                                                                                                                    |
| Player with subtitle overlay                             | Yes                                            | Dropped for now | Your media server's own apps play better than a browser player; Learnarr prepares you for them.                    |
| Follow along live with what's playing                    | Yes                                            | Later           | The most interesting next feature: the current line on your phone while the TV plays.                              |
| **Other**                                                |                                                |                 |                                                                                                                    |
| Songs (iTunes + LRCLIB lyrics)                           | Yes                                            | Later           | Keyless and cheap; fits once the core is settled.                                                                  |
| Books (EPUB, glossed EPUB)                               | On `feature/books`, unfinished                 | Later           |                                                                                                                    |
| Several learning languages per person                    | Yes                                            | No              | One language at a time; switching keeps everything per language.                                                   |
| Per-person onboarding                                    | Long, 8 steps                                  | Yes, short      | Languages and level on first sign-in; notifications in Settings.                                                   |
| Interface translation                                    | @nuxtjs/i18n, English (Polish on books)        | Yes             | @nuxtjs/i18n, every string in a catalog, plurals and language names from the browser. English only so far.         |
| PWA (installable)                                        | Manifest, push-only service worker             | Yes             | Same approach: no offline caching, always the server's current version.                                            |
| Admin                                                    | Users with tiers, job admin                    | Partly          | Users and system status; no tiers (it's a household, not a service).                                               |
| Public sign-up, anonymous trial, usage caps, GDPR pages  | Yes                                            | Dropped         | Learnarr is self-hosted for one household; sign-up is closed after the admin.                                      |
